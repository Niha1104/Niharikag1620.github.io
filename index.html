about.md

I'm a Data Engineer with 5+ years of experience designing and operating data pipelines that companies actually depend on — not proofs of concept. My focus is the unglamorous part that makes systems trustworthy: schema validation, reconciliation, idempotent reprocessing, SLA monitoring, and the kind of incremental design that survives a bad deploy at 2am.

I've worked across healthcare claims and financial-services data under real compliance constraints, and I build personal systems the same way I'd build a production one — recently that meant standing up a full real-time streaming platform from scratch: Kafka, Spark Structured Streaming, Delta Lake, Airflow, and dbt, wired to a live dashboard.

I lean on Generative AI tools deliberately — for debugging speed and documentation, never as a substitute for understanding what the system is actually doing.

projects/streaming-pipeline/README.md
featured · personal build

Real-Time Customer Engagement Streaming Pipeline

A complete real-time data platform, built and debugged from scratch: live customer engagement events flow through Kafka, get processed in real time by Spark Structured Streaming, land in a Delta Lake Lakehouse, get orchestrated by Airflow, modeled and tested with dbt, and surfaced on a live Angular dashboard — all running end to end in Docker.

  • Streamed live events through Apache Kafka, processed in real time with Spark Structured Streaming into bronze/silver Delta Lake tables (medallion architecture).
  • Orchestrated data-quality checks with Apache Airflow — scheduled DAG, retries, verified against real streaming data via both manual and scheduled runs.
  • Modeled and tested analytics-ready marts with dbt: staging + marts SQL models, 8 automated tests, all passing against live data.
  • Built a FastAPI backend and Angular dashboard to visualize daily active users, revenue, and event volume in real time.
  • Added GitHub Actions CI to validate Python syntax and dbt models automatically on every push.
